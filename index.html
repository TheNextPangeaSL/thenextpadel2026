Clasificación
Orden: Puntos → Victorias → Sets +/- → Juegos +/- → Directo
Normativa
Formato
  • Participan 9 equipos.
  • Fase regular: todos contra todos. Cada equipo juega 8 partidos y descansa 1 jornada (9 jornadas en total).
  • Cada jornada dura 2 semanas.
  • Playoffs: pasan los 4 primeros a semifinales (1º vs 4º, 2º vs 3º) y final.
Puntuación de liga
  • Partido ganado: 3 puntos
  • Partido empatado: 2 puntos
  • Partido perdido: 1 punto
  • Partido no jugado: 0 puntos
Desempates (en este orden)
  1. Puntos totales
  2. Victorias
  3. Diferencia de sets (sets ganados − sets perdidos)
  4. Diferencia de juegos (juegos ganados − juegos perdidos)
  5. Enfrentamiento directo (si aplica y resuelve el empate)
Resultados
  • Los resultados se comunican a Xuan, que los actualizará en la web
  • Se registra el resultado por juegos en cada set: 6-3, 4-6, 2-6.
  • Si termina 2-0, el set 3 se deja vacío.
  • Si por tiempo no se termina el partido, se puede marcar como empate mediante status=draw (lo hace Xuan).
